Save anything, keep everything.

Trove is a personal, Raindrop-style library. Save articles, videos, social posts, repos, papers, notes, browser bookmarks and your X bookmarks from any device or AI agent — the content itself is archived in your own Notion, so nothing is lost when the original disappears.

How it works

Uses your sessionReads bookmarks through x.com's own web API with your login. No paid X API.
Learns, doesn't guessRecords the request format your x.com tabs use and replays it, so X changes don't break it.
Notion fetches mediaPhotos and videos go straight from X's CDN into Notion. Your browser downloads nothing.
Sleeps when idleAn event-driven service worker with no content scripts. It only wakes to sync.

Install in two minutes

  1. Download the latest release zip and unzip it.
  2. Open brave://extensions or chrome://extensions, turn on Developer mode, click Load unpacked and choose the folder.
  3. Create a free internal integration at notion.so/profile/integrations, share a page with it, then paste the secret in Trove's settings and click Create new database.
  4. Stay logged in to x.com. Trove archives everything and keeps syncing.
